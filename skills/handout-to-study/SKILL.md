# handout-to-study（上課講義 → 逐頁講解 ＋ 重點複習）

把一份**上課投影片講義 PDF**變成兩份可以直接拿去讀的中文 Markdown。體例與品質基準＝
`<VAULT_ROOT>\<課程資料夾>\<講義資料夾>\` 底下已驗收的四份檔案（Ch2-3、Ch9 各兩份）。

**這個 skill 不做的事**（明確排除，不要自行擴充）：
- ❌ 併入同學筆記／他人整理的重點（Ch9 那次是特例）
- ❌ 跨講義比對（把另一份講義獨有內容併進來，Ch2-3 併 Part2 那次是特例）
- ❌ 翻譯（要逐句全譯請用 `/book-to-study`）
- ❌ 簡報產出（請用 `/paper-to-ppt`）

---

## 呼叫方式

```
/handout-to-study <講義PDF絕對路徑> [--exam <考古題PDF絕對路徑>]
```

| 參數 | 意義 | 缺少時 |
|---|---|---|
| `<講義PDF絕對路徑>` | 要處理的上課投影片 PDF | **缺少、或給的不是絕對路徑（只有檔名／相對路徑）時**，逐字問：**「要處理哪一份講義？請給 PDF 的完整路徑。」**<br>🚨 **不得自行到桌面或 `<VAULT_ROOT>\` 底下遞迴搜尋該檔名**（CLAUDE.md 鐵律 4：禁止遞迴掃大目錄）。一律問使用者。 |
| `--exam <考古題PDF>` | 選用。給了才跑 Phase 8（回頭標記考點） | 不問、直接跳過 Phase 8 |

**指令模糊時的固定提問**（使用者只說「幫我把這份講義弄一弄」之類）：
> **「確認一下：要產出的是『逐頁講解』＋『重點複習』兩份 md 嗎？（要翻譯請用 /book-to-study、要簡報請用 /paper-to-ppt）」**

得到肯定答覆才開跑。使用者若同時要求別的事（出考題、做簡報），**先把兩份筆記做完**，其餘另問。

## 套件需求（開跑前 preflight）

| 套件 | pip 安裝名 | import 名 | 用在哪 | 備註 |
|---|---|---|---|---|
| PyMuPDF | `pymupdf` | `fitz` | Phase 1 頁數／文字層、Phase 2 render | pip 名與 import 名不同 |
| Pillow | `pillow` | `PIL` | Phase 7 裁圖 | |

preflight：用 Write 工具把下列內容寫成 `<AI夾>\_preflight.py` 再執行（**不要用 `python -c`**，傳參層會吃引號與反斜線）：

```python
# -*- coding: utf-8 -*-
mods = [('fitz', 'pymupdf'), ('PIL', 'pillow')]
missing = []
for imp, pipname in mods:
    try:
        __import__(imp)
        print('[OK] ' + imp)
    except ImportError:
        missing.append(pipname)
        print('[MISSING] ' + imp + '  -> pip install ' + pipname)
print('MISSING_COUNT=' + str(len(missing)))
```

處置：`MISSING_COUNT` 非 0 → 跑一次 `python -m pip install <缺的套件>` → 再跑一次 preflight → 仍缺 → **停下回報使用者，不繼續**。

## 章節簡稱與主題名（`<簡稱>`／`<主題>`）

輸出檔名＝`<簡稱>_<主題>_逐頁講解.md`。範例（勿照抄）：`Ch9_Buck閉迴路_逐頁講解.md`、`Ch2-3_Buck_重點複習.md`。

**執行時機**：**在 Phase 0 之前**完成。Phase 0 的 G3 要用輸出檔名去 `Test-Path`，沒有簡稱與主題就查不了。

**主檔名的定義（機械）**：檔名去掉最後一個 `.pdf`；若剩下的字串**還有副檔名樣式的尾綴**（`.protected`、`.final`、`.v2` 等——正規式 `\.[A-Za-z0-9]{1,9}$`），**再去掉一層**。
例：`Part7_LDO.protected.pdf` → 主檔名 `Part7_LDO`；`Ch2_v2.final.pdf` → `Ch2_v2`。

**推導規則（機械）**：取上述主檔名，依序試：

1. 對主檔名跑**全域搜尋**（`re.findall`，**不要用 `^` 錨定開頭**）：`(Ch|Part|Week|week)\s*([0-9]+)`
   - 命中 **1 個** → 簡稱＝前綴＋數字（空白去掉）。例：`PMIC2026_week4` → `week4`；`Part7_LDO` → `Part7`。
   - 命中 **多個且前綴相同** → 用 `-` 串起。例：`Ch2 _ Ch3 - Operation...` → `Ch2-3`。
   - 命中 **多個但前綴不同** → 走第 2 步問使用者。
   - 命中 **0 個** → 走第 2 步問使用者。
2. 推不出來 → 逐字問使用者：
   > **「這份講義的章節簡稱要用什麼？（例：Ch9、Part7、week4）另外主題名要什麼？（例：Buck閉迴路、LDO）」**

**`<主題>` 一律問使用者確認**，即使推得出簡稱也要問，因為主題名決定筆記標題。固定句同上半句省略版：
> **「主題名要用什麼？（會出現在檔名與標題，例：Buck閉迴路、LDO、無線充電）」**

檔名不得含空格、括號、`/`。

## Phase 0：前置閘門（缺任一即中止，不繞過）

> **執行順序（硬規則）**：① 上面「套件需求」的 preflight → ② 上面「章節簡稱與主題名」確定 → ③ 才跑本 Phase。
> `_gate.py` 需要 `import fitz`，G3 需要輸出檔名，兩者都在前面。順序顛倒會撞 `ImportError` 或查錯檔名。

逐條檢查，**任一條 FAIL → 印出缺項清單、中止整個 skill，不執行後續任何 Phase**：

| # | 條件 | 檢查方式 | FAIL 時的訊號與處置 |
|---|---|---|---|
| G1 | 講義 PDF 存在 | `Test-Path '<路徑>'` | 印 `[ABORT] PDF_NOT_FOUND: <路徑>`；請使用者確認路徑 |
| G2 | 有文字層 | 見下方 `_gate.py`，全檔 `get_text()` 總字元數 **≥ 500** | 印 `[ABORT] NO_TEXT_LAYER: <字元數>`；告知這是掃描版，本 skill 不處理，不要自行 OCR 硬做 |
| G3 | 產出未存在 | `Test-Path` 兩個輸出 md | 存在 → **停下來問使用者**（見下方固定句），**絕不自動覆寫** |
| G4 | PDF 未加密 | `fitz.open()` 後 `doc.is_encrypted` 為 False | 印 `[ABORT] ENCRYPTED_PDF`；請使用者提供未加密版（`*.protected.pdf` 常屬此類） |

G3 的固定提問：
> **「`<檔名>` 已經存在了。要（1）接續補完 （2）整份重做（會覆寫） （3）換一個簡稱另存？」**

三個選項各自的動作（寫死，不要自行發揮）：

| 選項 | 動作 |
|---|---|
| (1) 接續補完 | **Read** `AI\_progress_<簡稱>.md` 全文 → 跳到其「下一步」那段所指的 Phase 繼續。**不得用 Write 重建進度檔**（會毀掉唯一的接續依據），只能在「已完成」段**追加**。若進度檔不存在 → 告知使用者無法接續，請他改選 (2) 或 (3) |
| (2) 整份重做 | 先把兩份舊 md 各複製成 `<原檔名>.<YYYY-MM-DD>.bak` 放同層，再從 Phase 1 重跑 |
| (3) 換簡稱另存 | 回上一節重新確定簡稱與主題，再從 Phase 1 開始 |

`_gate.py`（用 Write 工具落檔再執行）：

```python
# -*- coding: utf-8 -*-
import sys, fitz
p = sys.argv[1]
doc = fitz.open(p)
if doc.is_encrypted:
    print('[ABORT] ENCRYPTED_PDF')
    sys.exit(1)
n = doc.page_count
chars = sum(len(doc[i].get_text()) for i in range(n))
print('PAGE_COUNT=' + str(n))
print('TEXT_CHARS=' + str(chars))
if chars < 500:
    print('[ABORT] NO_TEXT_LAYER: ' + str(chars))
    sys.exit(1)
print('[OK] gate passed')
```

> 🚨 **頁數一律以 `doc.page_count` 為準**。系統／檔案總管標示的頁數會錯——Ch2-3 標 30 實際 64、Ch9 標 20 實際 44，兩次都錯。

**Phase 0 自查點**：輸入＝PDF 路徑；輸出＝`PAGE_COUNT`、`TEXT_CHARS` 兩個數字；檢查＝四條閘門全 PASS 且 `PAGE_COUNT` 已記進進度檔。

## Phase 2：整頁 render 成 PNG（150 dpi）

用本 skill 同資料夾的 `render_pages.py`。

**腳本合約**：

| 項目 | 內容 |
|---|---|
| CLI 簽名 | `python render_pages.py <PDF絕對路徑> <輸出資料夾絕對路徑> [dpi]`（dpi 選填，預設 150） |
| 輸出檔名 | `p01.png`、`p02.png`…**兩位數補零**；總頁數 ≥100 時自動改三位數 `p001.png` |
| 哨兵字串 | 先印一行 `[INFO] page_count=<N> dpi=<d> png_in_dir=<M>`；成功再印 `[DONE] rendered=<N> dir=<路徑>` |
| exit code | 0＝全部成功；1＝任一頁失敗（訊息 `[FAIL] page=<i>`）。**exit 0 就代表 N 張全部落地**，但仍須用 `Test-Path` 數檔複驗 |
| 覆寫行為 | 同名 PNG **直接覆寫**，不備份。重跑安全（冪等），輸出只由 PDF 決定 |

**規格（不要改）**：
- **整頁 render，不做圖區剪裁**。剪裁會配錯圖（book-to-study 曾整批配錯，見 lessons 2026-07-07）。
- dpi=150。要更清楚可調到 200，但兩份筆記全章要一致。

**Phase 2 自查點**：輸入＝PDF；輸出＝`img_<簡稱>\` 內 N 張 PNG；檢查＝`(Get-ChildItem (Join-Path '<dir>' '*.png')).Count` 等於 `PAGE_COUNT`（注意：`-Include` 不加 `-Recurse` 會回空值＝假陰性，不要用）。

## Phase 3：派 digest subagent 代讀圖形內容

文字層抓不到圖、也抓不到手寫註記。**主對話不得自己整批看圖**（CLAUDE.md 鐵律 6）。

**派工規則**：
- 每個 agent 最多 **32 頁**。切段演算法（機械，不要自己發明均分法）：**每段固定 32 頁，最後一段收尾**。
  例：44 頁 → p01–p32、p33–p44（2 個 agent）；118 頁 → p01–p32、p33–p64、p65–p96、p97–p118（4 個 agent）。
- agent 型別 `digest`，model **sonnet**。
- 回報檔寫到 scratchpad（不進主對話）：`<簡稱>_page_visuals_1.md`、`_2.md`…

**派工 prompt 必含下列逐字要求**（照抄，替換 `<>`）：

```
請逐頁讀 <img資料夾絕對路徑> 的 p<起>.png 到 p<迄>.png，每頁輸出一個區塊，欄位固定：

### P<NN>｜<投影片標題原文>
- **版面**：這頁有什麼（文字條列／電路圖／波形圖／方塊圖／表格／公式）
- **圖形內容**：圖上畫了什麼，座標軸與標註的文字逐字抄回
- **完整算式**：圖上印的算式**照原樣抄回**（文字層對分式常抽取碎裂，一定要從圖上讀）
- **紅色/彩色標記**：有哪些紅色或其他顏色的標示，逐項列出，並判定來源：
  - 「手寫」＝筆跡潦草、線條粗細不均、非標準字型
  - 「印刷」＝PowerPoint 規整圓角矩形、標準字型（Arial 等）粗體彩色字、向量繪圖線條
  - 判不準就寫【不確定】，**不要猜**
- **投影片上印出的提問**：若這頁印有問句（常是紅框），逐字抄回；沒有就寫「無」
- **頁腳印出的頁碼**：頁面下緣若印有頁碼數字，逐字抄回；沒有就寫「無」（**用來判定頁腳編號與 PDF 頁序是否錯位**，Phase 5a 的「⚠️ 頁碼說明」要靠這個欄位）

規則：看不清楚寫【不確定】；不要總結、不要評論、不要跳頁；一頁都不能漏。
```

**Phase 3 自查點**：輸入＝N 張 PNG；輸出＝回報檔區塊數合計＝N；檢查＝grep `^### P` 計數相符、頁碼無重複無缺漏。

## Phase 3b：主對話開圖複驗（不可省）

subagent 會把印刷紅字誤判成手寫（Ch2-3 那次兩個 sonnet agent 都誤判 p42）。主對話**必須親自 Read PNG** 複驗下列頁面：

1. 所有被標【不確定】的頁
2. 所有被判為「手寫」的頁（要對外宣稱「這是老師手寫重點」就必須自己看過）
3. 若上述兩類為 0，仍**隨機抽驗 3 頁**確認代讀品質

判準：**線條是否規整、字體是否為標準字型**。複驗結論寫進進度檔「踩過的坑」。

**紅色標記體例的分岔（機械判定）**：
- 複驗後確認**有**課堂手寫 → 兩份 md 用**雙標籤**：🖍️ 課堂手寫板書／🔺 投影片紅色標示
- 複驗後確認**全無**手寫 → 兩份 md 只用**單標籤** 🔺，並在「這份筆記怎麼用」註明本章無手寫板書。**不得**硬套雙標籤

**Phase 3b 自查點**：輸入＝代讀回報；輸出＝複驗清單（頁碼＋結論）寫進進度檔；檢查＝【不確定】與「手寫」兩類頁面 100% 被複驗。

## Phase 4：兩頁一組的分組

**規則**：
1. 預設**兩頁一組**，順序不變（P01–P02、P03–P04…）。
2. 內容自成一段、或與鄰頁講的不是同一件事 → **單獨占一組**（右半留空）。
3. 對照性質的兩頁（穩定 vs 不穩定範例、電路與其波形、補償器電路與其 Bode 圖）**刻意配成一組**，即使會打亂偶數配對。
4. 分組結果先列成表寫進進度檔（`區塊編號 | 頁碼 | 為什麼這樣配`），再開始寫。

奇數頁總數必然至少有一個單頁區塊，正常。

**Phase 4 自查點**：輸入＝N；輸出＝分組表；檢查＝所有頁碼各出現剛好一次、涵蓋 1..N。

## Phase 7：內文引用圖的裁切（只在需要時）

當 §3 推導或附錄要引用某張講義上的電路圖／波形圖時：**從該頁 PNG 裁切**，不要自繪。

用本 skill 同資料夾的 `crop_figs.py`。

**腳本合約**：

| 項目 | 內容 |
|---|---|
| CLI 簽名 | `python crop_figs.py <來源img資料夾> <輸出資料夾> <jobs.json路徑>` |
| jobs.json schema | 陣列，每筆 `{"src":"p37.png","dst":"<簡稱>_p37_type1.png","box":[0.03,0.132,0.99,0.885]}`；`box` 選填，省略時用預設值 |
| 預設 box | `(0.03, 0.132, 0.99, 0.885)`＝去掉頁面標題列與頁尾校名列。**這是 PMIC 課程投影片版式的實測值，換課程要先目視確認一張再批次跑** |
| 哨兵字串 | 每張印 `[CROP] <src> -> <dst> <px>`；全部成功時結尾印 `[DONE] cropped=<N>` 再接一行 `[REMINDER] 目視抽查…` |
| exit code | 0＝全部成功；1＝任一筆失敗（先印 `[FAIL] src=<檔名> ...`，結尾印 `[SUMMARY] cropped=<N> failed=<M>`，**此時不會有 `[DONE]`**）。**要檢查 exit code，不能只看有沒有 `[CROP]`** |
| 覆寫行為 | 同名直接覆寫，冪等 |

**引用時的排版（照這個寫，不要自創）**：圖**佔半個橫排**——用**和單頁投影片區塊一樣**的兩欄表格、**右欄留空**，說明文字寫在**表格下方**：

```markdown
| 講義 P<NN>｜<這張圖的標題> |  |
|:---:|:---:|
| ![](AI/img_crop_<簡稱>/<檔名>.png) |  |

<這張圖在講什麼、怎麼看>
```

> 🚨 **不要寫成「左圖右說明」的兩欄表格**（左格放圖、右格放說明）。那種寫法會讓 Phase 9 的 V8
> 直接報 ERROR（圖片列被當成表頭、找不到分隔列），而且已驗收的四份基準檔沒有一處這樣寫。

> 🚨 **裁切圖只放「逐頁講解」（`cssclasses: buck-slides`），不要放進「重點複習」**。
> CSS 的 `table:has(img)` 半欄寬規則**只掛在 `.buck-slides`**，`.buck-review` 沒有——放進重點複習
> 不會半欄寬、還會多一圈格線。已驗收的兩份重點複習檔圖片引用數皆為 **0**，照辦即可。

## 失敗路徑

| 情境 | 機械訊號 | 處置 |
|---|---|---|
| PDF 是掃描版 | `_gate.py` 印 `[ABORT] NO_TEXT_LAYER: <n>`，exit 1 | **中止整個 skill**，告知使用者這是掃描版、本 skill 不處理 |
| PDF 加密（`*.protected.pdf`） | `[ABORT] ENCRYPTED_PDF`，exit 1 | 中止，請使用者提供未加密版 |
| 產出 md 已存在 | `Test-Path` 回 True | **停下來問**「接續／重做／換簡稱」三選一，絕不自動覆寫 |
| 套件缺 | preflight 印 `MISSING_COUNT=<非0>` | pip install 重試一次；仍缺 → 停下回報使用者 |
| digest agent 因用量中斷 | 任務失敗通知含 limit 字樣 | **不要重派新 agent**：用 SendMessage 對原 agent 從斷點喚回續跑（context 保留） |
| 分組後圖片引用數 ≠ N | `verify_handout.py` V1 ERROR | 回 Phase 4 重列分組表再改 md，不要手動塞圖硬湊 |
| CSS snippet 不存在／未啟用 | `Test-Path` False 或 appearance.json 不含 | 產出照做，最終回報明講缺什麼、怎麼開，**不中止** |
| 使用者中途要求併入他人筆記／別份講義 | — | 說明這超出本 skill 範圍，可另開對話手動做；**不要自行擴充流程** |

## 常見問題

| 症狀 | 解法 |
|---|---|
| Obsidian 裡圖片變上下排列、大小不一 | CSS snippet 沒啟用：設定 → 外觀 → CSS 程式片段 → 開啟 `buck-slides`；或筆記 frontmatter 漏了 `cssclasses` |

| 心智圖要往下滑才看得完 | 佈局方向錯：鏈狀改 `graph LR`；寬樹用 `graph TD`。**縮小字級沒有用**（R13） |

| 摺疊區塊中途斷掉 | callout 內有裸空行。空行要寫成單獨一個 `>` |
| Obsidian 編輯模式正常、閱讀模式顯示舊圖 | Obsidian 圖片快取。改檔名（加版本後綴）或重啟 Obsidian |
