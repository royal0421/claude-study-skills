# Book to Study Skill（原文書章節 → 精讀筆記＋中文翻譯＋理解複習）

> **v1.0（2026-07-07）**：由《System Level ESD Protection》Ch1 黃金樣本逆向工程而成（設計檔 `<REPO_ROOT>\docs\specs\book-to-study-design.md`）。
> **Ch2 首跑＝驗證輪**：使用者可能先精讀完 Ch1 後提出格式修訂；執行前使用者若有新指示，以使用者指示為準，並照 `~\.claude\rules\maintenance.md` A/B 分級把修訂寫回本檔（改前備份）。可調旋鈕與預期修訂區見檔尾。

## 呼叫方式

```
/book-to-study <章節PDF絕對路徑>
```

- 未提供路徑時問：「請提供章節 PDF 路徑（可直接拖曳至終端機）：」
- 前置條件（Phase 0 逐一檢查，缺什麼 → 中止並告知怎麼補齊，不繞過硬做）：
  ① 章節 PDF 存在且有文字層；② 找得到整本書 PDF（章節夾 → 父夾；都沒有 → 問使用者）；③ 輸出檔名無衝突（或使用者已裁示接續/重做）。
- **多階段任務規定**：Phase 0 通過後，先在 `<章節資料夾>\AI\_progress.md` 建進度檔（五段：目標／已完成／下一步／踩過的坑／派工紀錄），每完成一個 Phase 立即更新——這是斷線與 compaction 的唯一保險。

## 與 paper-to-study 的分界（防混淆，兩邊慣例不互通）

| 項目 | paper-to-study（論文） | 本 skill（原文書章節） |
|---|---|---|
| 輸入 | 論文 PDF＋IEEE HTML 存檔（閘門強制） | 單章 PDF＋整本書 PDF；**無 HTML、無 Reference/ 下載** |
| 副產物夾 | `Claude\` | **`AI\`** |
| 產出 | 2 份（`簡稱_理解/翻譯.md`） | **3 份**（`<書簡稱>_ChN_精讀筆記/中文翻譯/理解複習.md`） |
| frontmatter | 必有 | 必有（v1.0 起；Ch1 舊檔無＝沿革特例） |
| callout | `> [!abstract]` 等 Obsidian callout | **禁用 callout**——用 emoji 標記框（🔬／〔延伸〕／⚠️／📐／📌） |
| 心智圖 | Mermaid flowchart LR | **禁用 Mermaid**——「全章心智圖」＝純清單＋blockquote＋表格 |
| 下標/數學 | HTML `<sub>` | **LaTeX**（`$V_h$`、`$$…$$`、`\boxed{}`）；禁用 `<sub>` |
| 圖片語法 | `<img src width="48%">` | **`![圖說](AI/figures/…)`**（一行一張、不加 width） |

## 共用推導規則

**書簡稱（全書固定，一次確認終身沿用）**：
1. 同書資料夾（父夾下各章節夾）已存在 `*_Ch*_精讀筆記.md` → **逐字沿用該前綴**，不另創。
2. 否則從書名取具辨識度簡稱（≤10 字元，英文縮寫或中文短名皆可），**印出請使用者確認後才定案**。
3. Ch1 既有三檔無前綴＝沿革特例：不改名、不比照（黃金樣本唯讀）。

**章號 N**：章節 PDF 第 1 頁 regex `Chapter\s+(\d+)` → 抓不到退資料夾名（`Ch` 或 `Chapter` 開頭＋數字，同腳本的 `Ch(?:apter)?\s*(\d+)`）→ 仍無 → 問使用者。

**書目行（三檔第一行 blockquote，逐字一致）**：
1. 同書其他章筆記已有 → 逐字沿用、只改 `Chapter N`（三檔書目行逐字相同，讀任一份皆可）。
2. 全書第一次跑 → 從書 PDF 卷前頁組出 `> 原書：<作者縮寫式>, *<書名>*, <出版社>, <年份>, Chapter N.`，**印給使用者確認**。
   格式範例（範例值，勿照抄）：`> 原書：V. Vashchenko & M. Scholz, *System Level ESD Protection*, Springer, 2014, Chapter 2.`

## Phase 0：前置閘門＋接續偵測

> 輸入＝章節 PDF 路徑。**缺任一條件 → 中止、印缺項清單、不執行後續任何 Phase。**

執行順序（步驟 1-3 合成一支 .py 落檔跑、一次查完、缺什麼一次報齊；步驟 4 若需使用者確認書簡稱＝互動點，等確認後才能算出步驟 5 的產出路徑——不要試圖把需等待回覆的步驟塞進同一支腳本）：

1. **章節 PDF 存在**：`Path(章節PDF).exists()`；否 → 中止：「找不到 <路徑>，請確認拖曳的是章節 PDF」。
2. **文字層**：PyMuPDF 開檔抽前 3 頁文字，合計 <500 字元 → 中止（失敗路徑表第 1 條）。
3. **整本書 PDF**：章節夾內「輸入 PDF 以外的其他 PDF」恰 1 個 → 用它；0 個 → 查父夾（書層）：父夾內 PDF 恰 1 個 → 用它；父夾也是 0 個、或任一層 ≥2 個無法判定 → **問使用者**：「找不到整本書 PDF（查過 <章節夾> 與 <父夾>）。請提供路徑；若真的沒有，回覆『沒有』改用降級模式（章節結構改由內文推斷、跨章參照省略）」。
4. **推導**：書簡稱、章號、書目行（上方「共用推導規則」）。
5. **接續偵測（冪等核心）**：算出三份產出完整路徑，逐一 `Test-Path`。任一存在 → 判斷完整性（機械判準：精讀筆記檔尾有「名詞速查」表標題；翻譯檔尾有含「全章總結」的 📌 小結；複習檔尾有「三檔分工」字樣）→ 印現況表（哪份存在、完整與否）→ **問使用者三選一**：接續（只補缺的檔/節）／全部重做（使用者明示同意才可覆寫）／中止。**絕不默默覆寫。**
6. **建 `AI\` 與 `AI\_progress.md`**（五段格式），preflight 套件檢查。

**Phase 0 自查點**：輸入＝章節 PDF 路徑。輸出＝GATE PASS 宣告＋章號＋書簡稱＋書目行＋書 PDF 路徑（或降級旗標）＋（若接續）起始點＋`AI\_progress.md` 存在。檢查＝已印 GATE PASS；書簡稱與書目行已經使用者確認（或沿用既有）；三份產出路徑已印出。

## Phase 1：擷取（跑 extract_chapter.py）

> 輸入＝章節 PDF＋書 PDF（或 NONE）。輸出＝`AI\` 下的 _extracted.txt、outline.json、sections\、figures\、figures.json。

### 腳本合約（extract_chapter.py，本 skill 資料夾自帶正本）

```
python "<SKILLS_ROOT>\book-to-study\extract_chapter.py" "<章節PDF>" "<整本書PDF或NONE>" "<章節資料夾>\AI" [章號]
```

- 參數順序固定：章節 PDF → 書 PDF（找不到書時填字面值 `NONE`）→ AI 資料夾 → 章號。**Phase 0 已推導出章號 → 呼叫時一律代入第 4 參數**（保證與 Phase 0 一致、不留給腳本重測）；僅 Phase 0 未能推導時才省略、讓腳本自動偵測。路徑一律絕對路徑加引號。
- **輸出檔名**（逐字）：`_extracted.txt`、`outline.json`、`figures.json`、`sections\sec_<N.X>.txt`（大節）與 `sections\sec_<N>_head.txt`（章首散文）、`figures\fig{章號}-{MM}.png`（MM＝Fig 編號兩位補零）、`figures\page_{P}.png`（P＝PDF 頁碼，不補零）。
- **哨兵與 exit code**（逐字）：
  - 成功尾行 `EXTRACT OK pages=.. sections=..(sliced=..) figs_detected=.. clipped=.. rendered_pages=.. missing=[..] unsliced=[..]`，exit 0。**exit 0 不代表圖全齊**——missing 非空仍 exit 0，必須讀尾行的 missing 與 unsliced。
  - `SCAN_PDF_NO_TEXT_LAYER` → exit 1：掃描版，中止整個 skill（失敗路徑表第 1 條）。
  - `CHAPTER_NUM_NOT_FOUND` → exit 1：補第 4 參數章號重跑一次。
  - `BOOK_TOC_EMPTY_FALLBACK_REGEX`：非致命警告行——書 toc 沒本章條目，結構已改用內文 regex，繼續。
- **覆寫行為（冪等）**：重跑覆寫 _extracted.txt／outline.json／figures.json，清空 sections\*.txt，刪 figures\ 內 `fig{本章號}-*.png` 與 `page_*.png` 後重抽；**絕不動 `aux-*.png`**（自繪圖安全）。
- 圖片擷取原理（供除錯）：定位圖說「Fig. N.M」→ 收集圖說附近版面繪圖元素 → 聯集區域 2x 剪裁算繪（向量/點陣通吃；Springer 邊欄圖說版式與傳統圖上說下版式都支援）；剪裁異常的圖退整頁 300 DPI 算繪（status: rendered_page）。

### 中間檔 schema（讀取前必看）

**outline.json**：
| 欄位 | 型別 | 說明 |
|---|---|---|
| `chapter` | int | 章號 |
| `sections[]` | list | 每筆 `{num:"2.3", title:"...", level:2或3, pdf_page:int或null}`（level 2＝大節、3＝小節；pdf_page 是章節 PDF 內頁碼，書 toc 換算失敗時為 null） |
| `book_chapters[]` | list | 每筆 `{chapter:int, title:"..."}`——寫「**Chap. N**」跨章參照時用；降級模式（無書 PDF）此表為空 → 跨章參照省略 |

**figures.json**：
| 欄位 | 型別 | 說明 |
|---|---|---|
| `chapter` | int | 章號 |
| `figs_detected[]` | list of str | 全章圖說掃出的 Fig 編號（如 `"2.5"`） |
| `items[]` | list | 每筆 `{fig:"2.5", page:int, file:"fig2-05.png", status:"clipped"或"rendered_page"}`；rendered_page 的 file 是 `page_P.png`（同頁多圖共用一檔） |
| `missing[]` | list | **結構上正常恆空**（腳本對每個偵測到的圖說必產出 clipped 或 rendered_page 之一）；非空＝腳本異常。**不可**拿「missing 為空」當圖片正確性證據——正確性關卡是嵌入前逐張視覺確認 |
| `unsliced_sections[]` | list | 沒切出文字檔的大節（正常應為空） |

**Phase 1 自查點**：輸入＝兩個 PDF。輸出＝上列檔案。檢查（逐條）＝
1. `EXTRACT OK` 尾行的 pages 與 PDF 頁數一致；sliced＝sections 數。missing 非空 → 依失敗路徑表第 4 條處置。unsliced 非空（某大節沒切出檔；文字**並未遺失**，仍在 _extracted.txt 內）→ 生成該節時改 Read `_extracted.txt` 的對應頁碼範圍（outline.json 該節 pdf_page 起、至下一大節 pdf_page 前一頁止），並記入 _progress.md。皆處置後才繼續。
2. `sections\` 檔數＝大節數＋head；任抽 1 檔開頭確認是對應節的內容。
3. **視覺抽查**：Read 抽 2 張 `clipped` 圖，確認圖內容與其 Fig 編號相符（圖左欄或下方帶原書圖說文字，可直接比對）。抽查失敗 → 全量降級為「嵌入前逐張視覺確認」（judgment.md §5 通則）。

## Phase 2：精讀筆記（<書簡稱>_ChN_精讀筆記.md）

> 輸入＝outline.json＋sections\*.txt＋figures.json＋書目行。輸出＝精讀筆記（章節資料夾根層）。

### 逐節生成協定（49 頁級長文的 context 保命規則，不可跳過）

1. 第一輪：Write 檔頭＝frontmatter＋導讀頭＋「如何使用這份筆記」＋全章心智圖的**過渡態**（標題先寫、內容以佔位注解暫代，逐字如下）：

   ```
   ## 全章心智圖（先看全貌）

   <!-- MINDMAP_PLACEHOLDER：所有節完成後回填 -->
   ```
2. 處理第一個大節前，先看 `sections\sec_<N>_head.txt`（章首散文；**此檔可能不存在**——章首無散文時腳本不會產生，不存在就直接從第一個大節開始）：有實質段落（不只是章名/標題行）→ 讀入，其要旨寫成第一個大節前的章首導言段（翻譯檔則完整譯出、不附小結）；僅標題無內文 → 略過並在 `AI\_progress.md` 註記。之後**一次處理一個大節**：Read `sections\sec_N.X.txt`（>25KB 的節分兩半處理）→ 生成該節完整內容 → Edit append 到筆記檔 → 更新 `AI\_progress.md` → 才讀下一節。**禁止一次 Read 多節、禁止整章一次生成。**
3. 全部節完成後：append 章尾三件套 → Edit 把 `<!-- MINDMAP_PLACEHOLDER：所有節完成後回填 -->` **這一行整行**替換為心智圖正式內容（條列＋blockquote 一句話＋數量級表；標題行第一輪已寫好、不動）→ 全文搜尋 `PLACEHOLDER` 確認 0 殘留。
4. 過程中發現「原書用文字帶過、畫出來會幫助理解」的概念 → 隨手記入 `AI\_aux_todo.md`（一行一項：候選圖名＋要表達什麼＋出處節號），Phase 4 統一畫。

## 如何使用這份筆記

- 每節固定區塊：**本節在講什麼 → 逐段精讀（含物理補充） → 圖解 → 關鍵表格 → 本節重點回顧**。
- 標記框：
  - 🔬 **物理補充**：原書沒細講、但理解必備的元件/電路物理。
  - 〔延伸〕：原書沒提，我補的相關概念（標準、量測、理論），幫你把知識接成網。
  - ⚠️ **常見誤解**：容易搞錯的點。
  - 📐 **數字重點**：值得記住的量化數字。
- 想快速複習：看每節開頭「本節在講什麼」＋結尾「重點回顧」＋全章最後的「考前濃縮」。

### 翻譯規則（逐條遵守）

1. **逐句全譯、零省略**：原書每個段落都要有對應譯文；禁止「（略）」「……」跳段；禁止【譯註】——任何補充一律歸精讀筆記的 🔬/〔延伸〕，本檔是「隱形譯者」。
2. **術語每次出現都寫「英文（中文釋義）」**（2026-07-07 使用者裁示，不採「僅首次」）。例：每次都寫 "ESD event（靜電放電事件）"。
3. **📌 小結不變式（機械公式）**：每個 level3 小節譯文後、每個 level2 大節的引言譯文後（引言極短也照附；全章 Summary 節除外）、與全章總結後，**都**有 `📌 **小結（<編號>）**`＋條列。**應有總數＝outline.json 的 level3 條目數＋level2 條目數**（Summary 節不寫引言小結、改寫「全章總結」小結，故總數恰為 L3＋L2）。Summary 節認定＝outline.json **最後一個** level2 條目**且其 title 含 "Summary" 或 "Conclusion"**；若不含（該章無總結節）→ 每個 level2 都照常寫引言小結、不寫全章總結小結——公式 L3＋L2 不變（最後節的一則從「總結」變「引言」），回報時標註該章無 Summary 節。（Ch1 樣本對過場式短引言未附小結；v1.0 改為「一律附」更機械、多幾則無害——屬可調旋鈕。）

## 失敗路徑（情境 → 機械訊號 → 處置）

| # | 情境 | 機械訊號 | 處置 |
|---|---|---|---|
| 1 | 掃描版 PDF 無文字層 | extract_chapter.py 印 `SCAN_PDF_NO_TEXT_LAYER`、exit 1（或 Phase 0 前 3 頁 <500 字元） | **中止**整個 skill，回報使用者：需 OCR 或改用電子版；本 skill 不做 OCR |
| 2 | 產出檔已存在（重跑） | Phase 0 步驟 5 Test-Path 命中 | **問使用者**三選一：接續／明示同意後重做／中止。絕不默默覆寫 |
| 3 | 整本書 PDF 找不到 | Phase 0 步驟 3 兩處 glob 皆空 | **問使用者**：給路徑；答「沒有」→ 降級模式（outline 靠內文 regex、book_chapters 為空、跨章參照省略並在筆記導讀頭註明） |
| 4 | 圖擷取缺漏 | figures.json 的 `missing` 非空，或視覺抽查發現剪裁錯圖 | **替代路**：對缺的 Fig 所在頁已有 page_P.png 則直接用之；沒有 → 用 .py 對該頁 `get_pixmap(dpi=300)` 補算繪；仍不可用 → 筆記文字帶過＋回報清單 |
| 5 | matplotlib 缺／CJK 字型失效（豆腐字） | preflight `[MISSING] matplotlib`；或視覺驗證見方框亂碼 | 裝一次重試 → 仍失敗 → **降級**：該 aux 圖以文字版縮排清單寫進筆記對應位置＋回報（aux 圖不擋三份主產出） |
| 6 | 章節超長／session 吃緊 | 章節 PDF >60 頁；或對話目測 >40 輪 | 停在完成的 Phase／大節邊界 → 更新 `AI\_progress.md`（含「下一步從 sec_N.X 接續」）→ 向使用者提議換新 session 接手（Phase 0 接續偵測天然支援） |
| 7 | 章號/書簡稱推導失敗 | `CHAPTER_NUM_NOT_FOUND`；或同書前綴掃描為空且書名無法縮短 | **問使用者**：請直接給章號/簡稱（一句話），填參數重跑 |
